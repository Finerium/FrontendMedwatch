# Archived Pages

These pages were authored as part of the original Vercel showcase but are not wired to the integrated MedWatch backend. They are preserved here (rather than deleted) for potential future use or reference.

Next.js App Router treats this directory as a private folder (underscore prefix), so none of these pages are accessible via URL.

- `molecule-viewer/` : Three.js molecule viewer (no backend equivalent)
- `drug-network/` : D3 force-directed drug interaction graph (no backend data)
- `indonesia-map/` : Choropleth map of patient distribution (PRD does not specify geographic distribution of clinic data)

To restore: move the desired folder back to `src/app/<name>/`.
